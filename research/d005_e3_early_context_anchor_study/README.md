# D005_E3 Early Context Anchor Study

Run from the repository root:

```bash
python -m research.d005_e3_early_context_anchor_study
```

E3 is an isolated, descriptive, uncapped anchor study. It reads protected
D005/E1/E2 artifacts and hash-verified source data. It does not authorize an
entry, calculate P&L, optimize a threshold, change a D005 gate, or connect to
production.
