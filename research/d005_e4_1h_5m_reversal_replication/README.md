# D005_E4 1H→5m Reversal Replication

Run from the repository root:

```bash
python -m research.d005_e4_1h_5m_reversal_replication
```

E4 is an isolated rolling-origin replication diagnostic. It does not authorize
an entry, calculate P&L, optimize a threshold, promote optional 1m or CISD,
change a D005 gate, or connect to production.
