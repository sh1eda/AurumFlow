# GitHub Discussions Recommendations

GitHub Discussions are useful for topics that are not bugs and do not yet need pull requests. Recommended categories:

- **Announcements**: maintainer updates and release notes.
- **Q&A**: usage questions, setup help, and clarification requests.
- **Research Ideas**: proposed experiments, validation approaches, and diagnostic improvements.
- **Backtest Reviews**: discussion of reproducible research outputs with data assumptions and limitations.
- **Documentation**: README, docs, examples, and onboarding improvements.

## Suggested Guidelines

- Do not present backtests as proof of future profitability.
- Include data source, timeframe, date range, costs, and configuration when discussing results.
- Mark speculative research ideas clearly.
- Move confirmed bugs to Issues.
- Move implementation-ready changes to Pull Requests.
